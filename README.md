# ZC-Tp — ZC-ZetCheaps Geometry Dash Texture Pack

A custom Geometry Dash texture-pack project in the ZC-ZetCheaps visual style.

## Style
- Deep purple and black palette
- Bright neon-purple accents
- Crisp, high-contrast edges
- Metallic white outlines
- Geometric details and gear motifs

## Planned files
- `textures/` — Geometry Dash texture assets
- `fonts/ZC_ZetCheaps_Game_Font.ttf` — custom TrueType game font
- `README.md` — project information

## Currency coin design
- Silver coin: ruble symbol (₽)
- Gold coin: 10 rubles
